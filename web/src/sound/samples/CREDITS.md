# Recorded sounds

Every file under this folder is CC0 (public domain dedication); each source page was checked for
its licence when the file was cut. A section per category, a row per file: the source file and
the second its cut starts at (a few milliseconds before the onset), and how long the cut runs.

Common modifications: downmixed to mono, high-passed, faded out over the last part of the cut,
levelled against the loudness of the recipe it plays for (EBU R128 max momentary loudness and the
loudest 50 ms; every take of a set at one level), and encoded as MP3 (shots 44.1 kHz 80 kbps,
the rest 32 kHz 56–64 kbps). Shots are also driven up to 9 dB into a tanh soft clipper, as the
synthesized shots are. Where a cut is a mix, its parts are listed.
